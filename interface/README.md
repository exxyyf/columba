# Columba viewer — просмотр DXA-снимков

TypeScript-интерфейс: галерея всех DICOM из `data/` с автоматическим
определением региона («Поясничный отдел позвоночника» / «Проксимальный отдел
бедра») и стороны бедра.

Классификацию выполняет пайплайн columba (эвристика по ширине кадра + CNN
этапа 1 + арбитраж) через bridge-скрипт `bridge/describe.py` — интерфейс
логику не дублирует, а показывает решения пайплайна. TypeScript отвечает за
сервер (Express), извлечение пикселей для отрисовки (`dicom-parser`) и UI.

## Запуск

```bash
cd interface
npm install
npm run dev            # сборка + сервер на http://127.0.0.1:8425
```

Требуется venv репозитория (`.venv`) с установленным columba; если веса CNN
(`artifacts/models/region_cnn.pt`) отсутствуют, работает чистая эвристика —
это отображается в сводке.

## Переменные окружения

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `PORT` | `8425` | порт сервера |
| `COLUMBA_PYTHON` | `<repo>/.venv/bin/python` | интерпретатор для bridge |
| `COLUMBA_SCAN_ROOTS` | `data/НД_для_обучения/Исследования` и `data/Для теста` | каталоги сканирования, через `:` |

Сканировать от корня `data/` нельзя: ключ исследования берётся из первого
компонента относительного пути, и парное разведение сторон бедра сломается
(подробнее — `stages/stage_1.md`, «Интерфейс просмотра датасета»).

## Что показывает интерфейс

- сводку (всего / позвоночник / бедро по сторонам / статус CNN / ошибки чтения);
- фильтры по региону и стороне, фильтр «Требуют внимания» (ошибки чтения,
  расхождения эвристики и CNN, неопределённый регион или сторона), поиск;
- карточки снимков с поправкой на анизотропию пикселя (1,05×0,6 мм,
  значения приходят из `columba.config`);
- модальное окно: полный путь, исследование, размер кадра, регион, метод
  арбитража, ответ CNN, признак стороны, дубликаты по пикселям.
